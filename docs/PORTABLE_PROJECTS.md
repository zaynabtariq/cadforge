# Save, reopen and continue editing

Use **Save project** to download a `.cadforge` file. Reopen it through the normal file input or drop zone. The app creates an independent workspace with the same applied geometry and active Undo chain. You can then select parts and continue editing in plain language. Use **Export STL** for a geometry-only manufacturing/interchange file. Apply or discard the preview before saving a project.

The project preserves original STL/STEP bytes, declared units, part meshes, applied command/selection/check history, and recorded feature/repair/learning provenance. It contains the active version and its ancestors; abandoned branch events remain history data, but their geometry and uncommitted previews are omitted. The live state after Undo is retained separately from the immutable snapshot so revision/history changes are not lost.

This preserves editable CADForge mesh history, not a reconstructed native CAD feature tree. The original STEP is retained separately; operations on its imported representation are still faceted mesh edits. Imported historical checks are labeled **reported provenance** and are not rerun or promoted into trusted runtime learning. Opening a project validates its meshes and structure, not the engineering truth of every historical claim.

The versioned archive is inert JSON with hash-addressed base64 data. No stored command or script executes during import. Import checks finite/duplicate-free JSON, blob hashes, mesh validity, the version graph and size limits before publishing a session. Paths and session/part/version IDs are regenerated. Limits are 100 MiB and 100 active ancestor versions. SHA-256 detects corruption; it does not establish authorship. STEP originals receive envelope validation and remain inert; imported meshes receive fresh geometry checks.

Independent tests cover a fresh empty workspace, exact geometry/source bytes, original STEP retention, multiple Undo steps, save-after-Undo and branched histories, continued edits, malicious paths, corrupt hashes, nonfinite numbers and broken graphs. Review caught malformed blob references that initially caused TypeError/server errors; they now reject with ValueError/HTTP 400 before publishing a workspace.

`scripts/test_project_studio_browser.mjs` exercises the real UI on the public plate STL: ordinary-language edit, Apply, Save project, native file-input reopen, exact export comparison, exact Undo, and another ordinary-language edit. The reopened session differs from the source session. Artifacts and the recording are under `artifacts/project-studio-test/`. Two live edit requests used 3,120 input and 109 output tokens (3,229 total). Saving, reopening and the malformed HTTP rejection made zero model calls; engineering authoring/discovery costs are not fully metered.
