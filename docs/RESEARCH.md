# Foundations and implementation boundaries

The supplied [Self-Improving CAD Generation Agents with Finite Element Analysis as Feedback](../2605.17448v2.pdf), Son et al., arXiv:2605.17448v2, motivates explicit blueprints, independent artifact checks, typed engineering failures and revision. CADForge implements typed dimensions, editable procedural geometry, STEP/STL round trips, actual BRep witnesses, failure history and parameter repair. It does not reproduce Hephaestus-CCX, CalculiX simulation, the paper's 21-view ParaView judge, or its reported scores. Four actual STL views are rendered for the demo. The supplied [ARTISANCAD](../2607.05750v2.pdf), Xu et al., arXiv:2607.05750v2, motivates parameterized executable procedures, reusable skills, dependency ordering and editable outputs. CADForge uses immutable command records and inherited DAG composition with separate regression promotion. It does not implement CATIA MCP, distill expert macro recordings, or establish industrial model quality.

CAD Sandboxes is used directly for local interactive STL previews. Its manufacturing quote/upload path is not part of generation or evaluation. Its original files remain supplied foundations, not code authored by this project. Fusion workstation lifecycle and native Autodesk/CATIA authoring require external configuration and are not claimed as working integrations.

The current CAD intermediate representation is a family plus a numeric parameter map. Ordered solid operations are implemented in versioned Python recipes. The learned command representation supports at-least, at-most, set, add and optional source-parameter affine dependence. Current demonstrated discoveries are scalar floors and parent composition; broader operation-level invention remains research work. Mutation tests reject filled apertures, collisions, false geometry and inconsistent source. They do not establish physical validity.

The grading question is answered by measured traces: a failure is diagnosed, the controller searches a repair, independent development cases verify it, and later designs inherit it. Discovery costs and transfer attempts are recorded. A manual engineering repair adding mounting holes is reported separately from automatically learned commands. Repeated model reviews alone are not evidence of self-improvement.
